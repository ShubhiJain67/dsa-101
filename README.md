# Data Structures & Algorithms

A pattern-based DSA interview prep repo, organized by technique rather than by random problem lists. Each folder below covers one core pattern: how to recognize it, the underlying mechanics, and a curated set of practice problems pulled from real interview question banks (with companies that ask them and links to LeetCode/GFG).

Built with SDE-level (mid-to-senior) interviews in mind — the concept sections go beyond "here's the code" and explain the reasoning, trade-offs, and common mistakes for each pattern.

## How each topic README is structured
1. **How to identify** — the phrases/constraints in a problem that signal this pattern
2. **Keyword → Technique cheat sheet** — quick lookup table for pattern recognition
3. **Core concepts** — the mechanics worth understanding deeply, with pseudocode where it's easy to get subtly wrong
4. **Practice problems** — grouped into concept sets, each with company tags and a link to the original problem

## Repo conventions
- Solutions are numbered Python files (`01_bfs.py`, `02_dfs.py`, ...) matching the row order in that topic's README
- 🔲 next to a problem means it isn't solved yet in this repo
